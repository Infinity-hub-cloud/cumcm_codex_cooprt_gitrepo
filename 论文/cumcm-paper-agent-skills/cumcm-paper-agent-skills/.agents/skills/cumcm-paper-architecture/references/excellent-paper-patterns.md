# Excellent CUMCM Paper Patterns

从学习素材中的优秀国赛论文提炼，作为结构倾向而非硬模板。

## 共性亮点

- 开篇迅速从题目实体进入数学任务，不长篇复述宏观背景。
- 整体流程图先交代全题路线；正文按问题递进展开。
- 常见强结构：数据/关系识别 -> 基础模型 -> 决策或优化 -> 不确定性/多因素扩展 -> 综合评价。
- 优秀目录会把“相关性/参数估计”作为后续优化的输入，而不是孤立章节。
- 模型名称明确，但算法服务于任务，不做方法名展览。
- 结果部分包含精确方案/指标，并配趋势图、对比表或敏感性证据。
- 同一基础模型在后问被扩展时，只说明新因素与新约束。
- 优点、不足与推广建立在模型真实结构上，而不是统一赞美。

## 值得避免

- 每问完全相同的四级模板；
- 每问都画流程图；
- 大量普通数据清洗占正文；
- 同一结果同时用图、表和正文逐项重复；
- 将“使用高级算法”本身当作创新；
- “模型合理、结果良好、现实意义重大”等无证据句。
