# Audit Checklist

## BLOCKER
- 关键结果无来源或来源冲突；
- 正文数字与程序/表格不一致；
- 错模型、错目标、错约束、错单位；
- heuristic 写成 proven global optimum；
- 相关/模型解释写成因果；
- 引用不存在或捏造文献；
- 赛题某问没有正文答案。

## MAJOR
- shared equation 在多个问题重复推导；
- 结果只有过程没有答案；
- 关键 claim 缺 validation 或 limitation；
- 图表没有正文 uptake；
- 数据处理改变样本口径但未说明；
- 符号复用/冲突影响理解；
- 目录按模板堆叠而非真实依赖。

## MINOR
- “针对问题X/首先/其次/最后”密集；
- “模型合理、效果良好、现实意义重大”等空话；
- 表格逐行复述；
- 公式只有“由此可得”无作用说明；
- 同类段落句长和语序高度重复；
- 标题首句同义复读；
- 不必要的流程图或装饰性可视化。
