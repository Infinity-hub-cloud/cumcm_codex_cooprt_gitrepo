## 证据引用规则

- 模型说明、实际运行结果、Codex 审计推断和待验证假设分开表述。
- 数值至少绑定数据版本、模型版本、运行目录、指标单位和人工状态；不能只引用 README 中的摘要。
- `runs/` 是不可变证据，`交付候选/` 是人工交付层，官方模板在 `../C题/附件/附件5/` 且保持只读。
- Q2 的人工模型接受不等于论文表转录完成或比赛文件提交批准。
- Q3 旧版结果采用已废止的附件 3 时间语义与费用模型，不能与修订版做正式价值比较。

## 项目内受限 Skills

`cumcm-paper-agent-skills/cumcm-paper-agent-skills/.agents/skills/` 中的 4 个 CUMCM 论文 skills 仅限本论文目录、其子目录或该工具包项目根目录使用，不得复制、安装或注册到用户级/其他项目的全局 skills 目录。供应方 README 与 `AGENTS.md` 保持原样；需要时按其边界读取。

- `cumcm-paper-intelligence`：建立来源可追溯的论文上下文，不重算科学结论。
- `cumcm-paper-architecture`：在事实锁定后组织论文结构、符号和图表计划。
- `cumcm-paper-draft`：只基于确认事实撰写，证据缺口保留 TODO。
- `cumcm-paper-audit`：审计任务覆盖、证据、公式符号与结论强度。

推荐顺序为 `intelligence → architecture → draft → audit`。当前优先等待 Q3 修订版人工运行和确认，不提前进入 Q4 或补造 Q3 数值。
