# 编程分区规则

仅当 Codex 要做数据处理方案落地、算法实现、运行记录、验证或受控优化时读取本文件。

- 放入：可执行代码、依赖最少的运行说明、参数配置、数据处理记录、日志摘要、结果表和复现信息。
- 不放入：原始附件的覆盖版本、未说明来源的派生数据、论文正文或他人分区文件。
- 原始数据保持不变；处理输出单独命名并关联输入版本、处理规则和生成时间。
- 每次优化只改变一个主要因素，并保留基线、警告、失败和负面比较。
- 向建模/论文分区交接时，交付指标定义、运行条件、最终结果、限制和文件路径；不直接修改对方分区。
