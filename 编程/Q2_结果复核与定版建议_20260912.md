## 三、为何当前适合定版

基础MILP已充分求解，继续收紧gap或换启发式算法缺乏直接降本依据。新的计算改善主要来自预测误差与五倍紧急购电成本的匹配，而不是求解器没找到足够好的解。

新增复杂度仅是确定性的星期匹配与固定残差分位数，未引入大型训练模型、情景树、在线参数寻优或额外优化决策变量；消融显示两部分都具有实际收益。因此推荐冻结该主模型，把时间用于论文解释、结果校核及后续问题的公平对照。

冻结内容：

| 项目 | 应固定的接口/规则 |
|---|---|
| 模型身份 | `M2-Q2-EXPERIMENT-weekday_buffer-v1.0`；实验选择`weekday_buffer`；轨道`B1_WEEKDAY_BUFFER_MILP_R0` |
| 负载点预测 | 最近已完成的同自然星期、同刻；历史不足退回最近已完成同刻 |
| 光伏点预测 | 最近已完成同刻，保持原法 |
| 风险缓冲 | 最近28天、同刻净负载残差 `(L-PV)-(Lhat-PVhat)`；至少7个有效样本；正部0.8分位数；按历史预测原决策时刻重建残差 |
| 规划输入 | `planning_load = load_pred + risk_buffer`；actual与点预测字段保持原义 |
| 信息集 | 每日00:00，只允许来源区间结束时刻不晚于00:00；附件3/4不进入Q2 |
| 时间标签 | 瞬时标签向后保持10分钟；模板slot1为00:10—00:20，slot144为次日00:00—00:10；slot144用次日自然星期 |
| SOC | 1月开始连续推进；自然日首10分钟承接前日slot144；2月不重置；不套用Q1每日首末相等约束 |

| 数值输出 | 内部全精度；导出四位小数；汇总先加未舍入量再舍入 |
| 数据版本 | `PREP-TIME-REV-20260911T170805+0800` |

0.8来源于简化单时段费用权衡，不是跨期储能最优性证明或80%可靠性保证。后续若确需优化，应另建版本与独立运行目录，预先固定滚动验证办法；不得用事后实际值修改当天计划。终端价值、实时储能纠偏、情景规划等不属于本次冻结主线。
