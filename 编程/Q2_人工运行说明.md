## 6. 人工正式运行 Q2

仅在上述检查通过且人工明确决定开始正式运行时执行。输出目录必须不存在；程序拒绝覆盖任何既有运行包。

```powershell
Set-Location -LiteralPath 'F:\2026数模国赛\国赛团队共享工作区\编程'
$q2Stamp = Get-Date -Format 'yyyyMMdd_HHmmss'
$q2Output = Join-Path (Resolve-Path '.\runs').Path ("q2_human_run_" + $q2Stamp)
python -m q2_baseline.cli run --config '.\config\q2_baseline.json' --output-dir $q2Output
Write-Output $q2Output
```

运行顺序固定为：2025-01-01 至 2025-01-31 预热，再从 2025-02-01 连续推进至 2025-12-31。2月1日不重置 SOC。1月费用只进入 `warmup`，不进入正式 Q2 总费用。

建议同时把控制台保存下来：

```powershell
$q2Stamp = Get-Date -Format 'yyyyMMdd_HHmmss'
$q2Output = Join-Path (Resolve-Path '.\runs').Path ("q2_human_run_" + $q2Stamp)
$q2Console = Join-Path $q2Output 'human_run_console.log'
python -m q2_baseline.cli run --config '.\config\q2_baseline.json' --output-dir $q2Output 2>&1 | Tee-Object -FilePath $q2Console
```

注意：程序会自行创建 `$q2Output`，但 `Tee-Object` 在进程启动前需要父目录存在，不能把日志直接写入尚未创建的 `$q2Output`。因此实际推荐用下面这个不会冲突的版本：

```powershell
$q2Stamp = Get-Date -Format 'yyyyMMdd_HHmmss'
$q2Output = Join-Path (Resolve-Path '.\runs').Path ("q2_human_run_" + $q2Stamp)
$null = New-Item -ItemType Directory -Force '.\human_run_logs'
$q2Console = Join-Path (Resolve-Path '.\human_run_logs').Path ("q2_human_run_" + $q2Stamp + '.console.log')
python -m q2_baseline.cli run --config '.\config\q2_baseline.json' --output-dir $q2Output 2>&1 | Tee-Object -FilePath $q2Console
```
