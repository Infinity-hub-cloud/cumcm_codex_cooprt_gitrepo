## 2. 人工授权后才可执行

正式授权必须明确输出目录、轨道和用于 `Q4_2_NOSTORAGE` 的同一价格预测器。每次只能使用一个全新目录；失败立即停止并保留错误文件。

每条轨道完成后使用显式 UTF-8 读取 JSON。Windows PowerShell 5.1 不得省略 `-Encoding UTF8`，否则中文路径可能被错误解码并导致 `ConvertFrom-Json` 报“无法识别的转义序列”。

```powershell
$track = 'Q4_2_PRICE_CANDIDATE_P1' # 改成刚完成的轨道
$trackRoot = Join-Path $q4Root $track
$manifest = Get-Content -LiteralPath (Join-Path $trackRoot 'run_manifest.json') -Raw -Encoding UTF8 | ConvertFrom-Json

$export = Get-Content -LiteralPath (Join-Path $trackRoot 'export_validation.json') -Raw -Encoding UTF8 | ConvertFrom-Json
[pscustomobject]@{
    status = $manifest.status
    formal_days = $manifest.formal_days
    initial_soc_feb1 = $manifest.initial_soc_feb1
    assertions_passed = $assertions.passed
    export_passed = $export.passed
}
```

$predictorByTrack = @{
    Q4_2_PRICE_BASELINE_P0  = 'P0_RECENT_SAME_CLOCK'

全部轨道完成并人工确认成本后，生成统一成本映射和价值分解：

```powershell
$costs = [ordered]@{}
$costs['REF_Q2_FIXED_PRICE_FROZEN'] = [double](Get-Content -Raw -Encoding UTF8 "$q4Root/REF_Q2_FIXED_PRICE_FROZEN/run_manifest.json" | ConvertFrom-Json).reference_cost_yuan
foreach ($track in @('Q4_2_PRICE_UNAWARE_RESETTLEMENT') + $priceTracks + @('Q4_2_NOSTORAGE')) {
    $row = Import-Csv "$q4Root/$track/metrics_summary.csv" | Where-Object metric -eq 'realized_total_cost'
    $costs[$track] = [double]$row.value
}
$costsJson = "$q4Root/costs.json"
[System.IO.File]::WriteAllText((Join-Path (Get-Location) $costsJson), ($costs | ConvertTo-Json), [System.Text.UTF8Encoding]::new($false))

# 8. 生成价值分解。
python -m q4_baseline.cli --config config/q4_baseline.json compare --costs-json "$costsJson" --selected-predictor "$selectedTrack" --output "$q4Root/value_decomposition_q4_2.json"
```

`REF_Q2_FIXED_PRICE_FROZEN` 是历史固定价锚点，只用于描述价格制度差异。`Q4_2_PRICE_UNAWARE_RESETTLEMENT` 才是 price-awareness 价值的主参考。`PriceAwarenessValue_*` 必须定义为同价格重结算成本减候选实际成本，不能改写为 Q2 固定价格成本减 Q4 成本。
