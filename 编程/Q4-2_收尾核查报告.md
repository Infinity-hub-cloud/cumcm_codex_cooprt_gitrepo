## 5. 下一条人工命令

由于当前身份门禁失败，不能把当前 F 盘下单独补跑的 P2 无储能轨道与旧 P2 有储能包混合比较。应先在当前 F 盘以同一源码、同一配置完成完整重跑；在该重跑中 P2 有储能轨道产生后，唯一需要追加的无储能命令为：

```powershell
$q4Root = 'runs/q4_2_<new_timestamp>'
python -m q4_baseline.cli --config config/q4_baseline.json run --track Q4_2_NOSTORAGE --predictor P2_EWMA --output-dir "$q4Root/Q4_2_NOSTORAGE" --allow-formal-human-run
```

该命令只能由人工执行，输出目录必须是全新目录。P2 无储能完成后，才可生成新的 `value_decomposition_q4_2.json`，并同时保留 P0/P1/P3 的 price-awareness 值和 `PriceSystemEffect`。
