# 建模分区规则

仅当 Codex 要做题意拆解、变量与假设、目标与约束、评价体系、模型比较或优化路线时读取本文件。

- 放入：确认后的题意解释、模型卡、指标定义、约束与假设、路线比较、给编程手的实现规格、给论文手的模型说明。
- 不放入：原始附件副本、可执行代码、运行日志、论文全文或排版文件。
- 每份结论写清题号/子问题、输入来源、版本、状态（待确认或已确认）和交接对象。
- 需要编程实现时，只交付输入输出、变量单位、目标、约束、参数、验证和预期结果；不修改 `编程/`。
