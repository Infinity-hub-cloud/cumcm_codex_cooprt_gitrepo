## 已锁定的共同口径

- 模型采用 144 个 10 分钟物理区间，附件标签按已确认的左端点瞬时功率语义映射；模板顺序不得循环平移。
- 储能按母线侧充放电，`eta_c = eta_d = 0.9`，SOC 范围 1200–10800 kWh，最大功率 5000 kW，`qmax = 5000/6 kWh` 使用内部精确值。
- Q1 首末 SOC 均为 6000 kWh；Q2/Q3 SOC 跨日连续；同一时段充放电二进制互斥；不售电。
- “充放电效率为 90%”存在解释歧义；当前人工确认基线采用充、放电效率分别为 90%，总往返效率 0.81。总往返效率 90% 只能作为后续敏感性方案。
