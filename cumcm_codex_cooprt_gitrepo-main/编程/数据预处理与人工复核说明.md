# C 题数据预处理与人工复核说明

> 阶段：数据预处理与人工审计  
> 状态：时间语义修订版正式审计已完成（`PASS`）；等待人工核验报告与规范化数据  
> 禁止：本阶段不训练预测器、不调用优化器、不生成任何 `result*.xlsx`

## 1. 脚本

主脚本为 `preprocess_audit.py`，只读解析：

- `正式比赛C题/附件/附件1.xlsx`；
- `正式比赛C题/附件/附件2.xlsx`；
- `正式比赛C题/附件/附件3.xlsx`；
- `正式比赛C题/附件/附件4.xlsx`；
- `正式比赛C题/附件/附件5/*.xlsx`；
- 输入目录下其他文件的 SHA-256 清单（包括题面 PDF 和理解文档）。

脚本不会写入、改名、覆盖或删除输入目录中的任何文件。

## 2. 环境与运行

使用 Python 3.11 或兼容版本，并确认 `openpyxl` 可导入：

```powershell
python -X utf8 -c "import openpyxl; print(openpyxl.__version__)"
```

建议从 `编程` 目录运行单元测试：

```powershell
python -X utf8 -m unittest -v test_preprocess_audit.py
```

此前 `预处理审计输出/` 使用旧“区间右端点”语义生成，已经失效，不得继续作为建模输入。修订版正式输出目录为：

```powershell
python -X utf8 preprocess_audit.py `
  --input-root "D:\Users\LENOVO\Desktop\数学建模\正式比赛C题" `
  --output-dir "D:\Users\LENOVO\Desktop\数学建模\国赛团队共享工作区\编程\预处理审计输出_时间口径修订版"
```

若需重复运行，必须指定新的空目录；脚本会安全退出而不覆盖已有输出。

脚本已在全新临时目录完成技术烟测（`PASS`、0 错误、0 警告），并验证 Excel 临时锁文件会被跳过；烟测只证明程序可运行，不构成人工验收或模型输入确认。

## 3. 输出结构

脚本会生成：

```text
预处理审计输出_时间口径修订版/
├─ normalized/
│  ├─ attachment1_single_day.csv
│  ├─ attachment2_actual_long.csv
│  ├─ attachment3_forecast_long.csv
│  ├─ attachment3_mapped_10min.csv
│  └─ attachment4_actual_price_long.csv
└─ audit/
   ├─ audit_report.md
   ├─ audit_summary.json
   └─ manifest.json
```

规范化 CSV 中的功率、价格及派生区间能量按 4 位小数写出；审计统计和后续模型仍须使用未舍入的内部值。附件 3 的日期向下补齐只发生在派生输出中，原附件保持不变。

附件 1、2、4 的字段均按瞬时时刻解释，并以左端点零阶保持映射到随后 10 分钟：`0:10` 对应 `0:10-0:20`，`0:00+1` 对应次日 `0:00-0:10`。规范化文件显式给出样本时刻、区间起止日期和分钟，避免跨日含义丢失。

## 4. 人工复核顺序

请先打开 `audit/audit_report.md`，再按以下顺序处理：

1. 确认输入目录路径、生成时间和文件 SHA-256 与本机附件一致；
2. 确认附件 1 的工作表、表头、144 个瞬时时刻、首尾时间和非负范围；确认第一项映射到 `0:10-0:20`，末项映射到次日 `0:00-0:10`；
3. 确认附件 2 的两个工作表均覆盖完整日期，日期无重复，时间轴连续，负载/光伏无缺失、非有限和负值；
4. 确认附件 3 的日期向下补齐、四个发布时间、24 小时预测列、负值检查，以及跨日目标的 10 分钟映射；
5. 确认附件 4 的日期、时间轴、价格范围；若出现负价格，先不要进入模型求解，等待人工决定有界性处理；
6. 确认附件 5 各结果模板的工作表名、行列数、首尾日期和表头；
7. 确认五个模板的计划/调整购电表均严格从当日 `0:10-0:20` 到次日 `0:00-0:10`，且审计报告不再产生 `BLOCKER-TIME-001`；
8. 检查报告中的所有 `ERROR` 和 `WARNING`，逐项写出“关闭 / 保留 / 升级为 BLOCKER”的人工决定。
