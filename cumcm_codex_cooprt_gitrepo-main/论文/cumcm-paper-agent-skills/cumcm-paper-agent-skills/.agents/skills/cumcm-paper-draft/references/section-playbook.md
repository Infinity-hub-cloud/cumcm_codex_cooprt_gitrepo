# Section Playbook

## 问题重述
压缩背景，准确重述实体、任务和输出。不要提前声称方法优越。

## 总体/分问问题分析
说明数学结构、继承关系、新困难、新增变量/目标/约束和最终要回答什么。避免算法教程。

## 模型假设
只列真正参与推导或限定适用范围的假设，并尽量说明必要性；不要写“忽略一切次要因素”式废话。

## 符号说明
只收正文高频/承重符号。变量首次出现附近仍应能理解其含义。

## 数据预处理
保留改变统计含义、样本口径或模型输入的处理；普通格式清洗一句带过。

## 模型建立
从变量和关系到目标/评价量与约束。共享核心先定义，后问只写变化部分。承重公式给编号。

## 模型求解
说明为什么该求解法匹配非线性、离散连续耦合、非凸、多目标或计算代价；写题目特定处理，不写教科书算法步骤。

## 结果与分析
Answer -> Pattern -> Interpretation -> Boundary。完整参数进表，正文只提炼会改变评委理解的结构。

## 验证/敏感性
Claim -> Method -> Outcome -> Remaining weakness。明确扰动变量、范围、对照和未证明事项。

## 模型评价与推广
优点必须对应具体结构/验证；不足对应假设、数据、算法或外推边界；推广说明哪些数学结构可复用及需要重估什么。

## 摘要
另行遵守 math-modeling-paper-pro 的 abstract guidance；核心是问题递进 + 决定性数值 + 最强验证 + 边界，不写算法清单。
